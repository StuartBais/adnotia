Adnotia phone app directions

Three design directions for the rebuilt phone app. Open any file directly. Research and notes are in RESEARCH.md and README.md.

Ribbon

A continuous vertical time ribbon where each task is a segment; the running task fills with progress so time is felt, not read.

Ledger

High-contrast ruled lines and large serif type turn every task into a clear ledger entry; the running item is a bold left bar.

Beacon

The running task is a large central beacon with a circular timer; everything else is a quiet satellite row.
