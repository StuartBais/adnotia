Springform

A Material 3 Expressive day where shape is the second voice. The running task is the one big cobalt container, each step changes silhouette when its state changes, and the thing to press is always the largest button on the screen.

Draws on
Material 3 Expressive in Compose: the expressive corner scale, five button sizes, button groups, the 80 dp FAB, the 64 dp bar, spring motion.
Typeface
Google Sans Flex, variable, bundled. Tabular numerals throughout. Roboto Flex if tnum is missing.
Colour
Its own tonal scheme from a cobalt seed, Dynamic Color off. No error role, so nothing in the app is red.
